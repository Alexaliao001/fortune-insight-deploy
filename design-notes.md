# Structured Report UI Design Notes

## Key Design Patterns from Research

### Tarot Report UI
- Card visual display: Show actual card images with position labels (Past/Present/Future)
- Each card gets its own interpretation card with keywords, meaning, and position context
- Overall synthesis panel at the bottom
- Dark mystical theme with purple/blue gradients
- Card flip animation for reveal

### BaZi Report UI  
- Four Pillars displayed in a grid (Year/Month/Day/Hour)
- Each pillar shows Heavenly Stem + Earthly Branch with Chinese characters
- Five Elements distribution shown as colored bar chart or pie chart
- Ten Gods relationships displayed
- Luck Cycles (大运) shown as timeline
- Color coding: Wood=green, Fire=red, Earth=yellow, Metal=white/gold, Water=blue/black

### Horoscope Report UI
- Score gauges/meters for each category (Overall, Love, Career, Wealth, Health)
- Lucky items displayed as badges (color, number)
- Planetary context shown as info cards
- Zodiac sign profile card with traits

### Dream Report UI
- Symbol cards with Jungian archetype labels
- Theme identification panel
- Psychological insight sections
- Emotion color mapping

## Design Principles for Paid Reports
1. Free: Show summary scores + blurred/locked detailed sections
2. Paid: Full structured report with all visualizations
3. Use gradient blur overlay for locked content
4. Clear CTA button to unlock
