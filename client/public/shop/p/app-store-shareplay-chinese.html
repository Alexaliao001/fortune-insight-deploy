What good zh-Hans SharePlay listing copy looks like

Align tone with your en-US listing and name the shared-session surfaces buyers actually see:

  • Name & subtitle (30 chars each) — lead with the outcome (与好友同步观影, 语音同听播客) not SDK jargon
  • Keywords (100 chars) — Simplified Chinese queries for shared viewing, FaceTime sync, co-listening where relevant — not English API names stuffed into the hidden field
  • Description — one clear paragraph on what syncs (视频进度, 播放列表, 训练节奏) and that sessions run through FaceTime shared experiences
  • Screenshot captions — one line per frame naming the on-screen session state: "FaceTime 通话中同步播放" not "SharePlay"
  • Honest scope — if SharePlay requires login, premium tier, or specific content rights, say so in plain zh-Hans

SharePlay screenshot captions Chinese buyers expect

Media, fitness, and social apps often dedicate one or two gallery frames to the shared-session story — FaceTime PiP over your player, invite sheet, or synchronized controls. Overlay lines on those frames should name the feature in plain zh-Hans:

  • Shared video frame — describe sync: "与好友 FaceTime 同步观影，进度一致" instead of "Watch Together" alone
  • Shared audio frame — name the content type: "一起听播客，实时同步进度" vs vague "Listen Together"

  • Match caption to capture — if the screenshot shows three participants, the overlay should say 多人同播 not 双人观看
