Screenshot captions vs App Preview vs listing fields

App Store Connect treats visual gallery copy separately from searchable listing fields on the zh-Hans localization row:

  • Screenshot overlay captions — short lines on each gallery frame that name what the user sees on screen. Buyers skim these in the first three seconds; empty or English-only overlays on a zh-Hans page signal neglect.
  • App Preview text — title and description fields tied to optional video previews in your gallery. When you use App Previews on the China storefront, zh-Hans preview copy should match the workflow shown — not a translated US script.
  • Title, subtitle, keywords, description — searchable and evergreen listing fields. Overlay captions do not replace them and should not repeat the same nouns in every frame.

This page covers screenshot overlay captions and App Preview text only — not title, subtitle, keyword field, description, What's New, or promotional text. For those fields, see our Simplified Chinese keywords guide, What's New guide, or China storefront listing guide.

Common mistakes on zh-Hans screenshot captions

  • Leaving English overlay lines on a Simplified Chinese gallery while the rest of the listing is zh-Hans
  • Pasting Google Translate output with formal false cognates (“专业级”, “强大”) that read as template copy on image art
  • Repeating the app name or subtitle on every frame instead of naming the on-screen action
  • Stuffing search keywords into overlay captions — Apple indexes title, subtitle, keywords, and description, not screenshot overlay text for Search
  • Showing Chinese UI in captures with English overlays claiming “full English support” — or the reverse mismatch
  • App Preview description copied from the US page without matching the zh-Hans screenshots users actually see

Better zh-Hans screenshot captions reduce product-page bounce — they do not replace in-app UI localization, screenshot re-export, or Apple review decisions.

What good zh-Hans screenshot captions look like

Each overlay should state one concrete outcome — six words or fewer on phone widths. Frame one should mirror your title's promise. Middle frames walk the core workflow. The last can mention pricing or privacy — not unverifiable download counts:

  • Name the feature in plain Chinese: “新增桌面小组件” not “优化用户体验”
  • One line per frame in a spreadsheet with character counts before you re-export assets
  • Match tone to your description — casual productivity app vs professional tool
  • App Preview title: one clear clause naming the workflow shown in the video
  • App Preview description: one or two sentences on what changed — not a second full description

zh-Hans overlay lines can differ idiomatically from en-US captions when the workflow is the same — avoid mirroring comma-heavy brochure lines from your English page onto image art.
