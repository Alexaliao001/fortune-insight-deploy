Standalone sticker pack vs iMessage extension app

Apple supports two distribution shapes for Messages stickers. Both have an App Store product page with the same listing fields — name, subtitle, keywords, description, promotional text, and screenshots — each with per-locale rows in Connect.

Standalone sticker pack app

A sticker-only app with no companion iOS app shell. Users discover it on the App Store, install it, and the stickers appear in the Messages app drawer. The product page often leads with a sticker grid preview screenshot and frames showing stickers inside a conversation bubble layout. All listing metadata lives on this single app record.

iMessage extension app

A full iOS app plus a Messages extension target — stickers ship inside the extension while the parent app may offer settings, IAP, or a catalog browser. App Store Connect shows one product page for the parent app; screenshot captions often mix in-app UI with Messages drawer shots. The zh-Hans row covers the parent app listing — not a separate extension URL — but your gallery should show how stickers look in Messages for China buyers.

AppLocale rewrites listing metadata for either shape. We do not compile sticker binaries, configure extension entitlements, or split parent-app vs extension bundle IDs — those are Xcode tasks.

What China buyers still see in English

Sticker pack listings fail zh-Hans completeness in predictable places — especially when the en-US page was designed around English Messages vocabulary:

  • App name and subtitle — Latin character names, "Sticker Pack for iMessage", or pinyin instead of 表情包 / 贴纸 search terms China users type
  • Keyword field — English emotion words (happy, cute, cat) that do not map to zh-Hans queries like 可爱, 猫咪, 斗图
  • Description — English brochure listing sticker count and "compatible with iMessage" instead of plain Chinese explaining pack theme and usage
  • Sticker-grid screenshot captions — overlay lines reading "Stickers", "50+ stickers", or theme names in English on the grid preview frame
  • Messages thread screenshots — captions describing "Tap to send in iMessage" or character names (Mochi, Pixel Cat) left untransliterated
  • Pack theme labels — Holiday Pack, Office Mood, Kawaii Friends as English overlay text on otherwise localized art
  • Promotional text — empty or English-only limited-time lines when you add seasonal sticker drops

Better zh-Hans listing copy reduces product-page bounce for sticker searches — it does not replace sticker artwork localization inside the Messages drawer, App Review decisions, or Apple's in-app sticker recommendations.

zh-Hans keyword habits for sticker pack Search

China users search for stickers with Simplified Chinese terms — not English pack titles or pinyin romanization. The 100-character keyword field and visible subtitle should reflect how people describe sticker packs on the China storefront:

  • 表情包 — broad term for sticker/expression packs; high competition but expected in category vocabulary
  • 贴纸 / 表情 — shorter alternatives when character budget is tight
  • Theme nouns — 猫咪, 职场, 节日, 动漫 — match your pack art, not generic English adjectives
  • iMessage — some users include it; do not waste the entire subtitle on the word "iMessage" when 30 characters could carry theme + format
  • No pinyin stuffing — keaimao or biaoqingbao in the keyword field does not index like 可爱猫 or 表情包; see Pinyin vs Simplified Chinese

Sticker-grid and Messages screenshot captions

Sticker listings rely heavily on visual gallery frames. Connect stores overlay caption text per screenshot separately from name, subtitle, and keywords. Typical sticker-pack gallery structure:

  • Frame 1 — grid preview — shows sticker thumbnails; caption names pack theme and count in plain Chinese
  • Frame 2 — Messages drawer — sticker browser open; caption explains how to find the pack after install
  • Frame 3 — conversation send — sticker in a thread; caption shows the send gesture without English "Tap to send"
  • Frame 4+ — character or season highlights — feature subsets; captions name characters in Chinese or transliterated hanzi when brand-locked

If your screenshots embed English text inside the PNG art — character speech bubbles, logo marks — that requires a design re-export.
