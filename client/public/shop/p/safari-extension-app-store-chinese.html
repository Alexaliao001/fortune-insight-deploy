Extension screenshot captions are a separate craft

Safari extension listings lean heavily on toolbar and popup screenshots — small UI surfaces with tight caption budgets. Generic phone-app screenshot copy rarely fits a 390×844 frame showing a browser toolbar icon and a narrow popup panel.

  • Toolbar context — captions should name what the icon does in one line, not repeat the full app marketing tagline
  • Popup panel — outcome-first phrasing for the action visible in the capture (save page, translate selection, fill password)
  • Permission prompt frames — explain the user benefit in zh-Hans overlay text; the system dialog itself stays in the user's device language
  • Before/after browsing — comparison frames need parallel zh-Hans labels on both sides, not English "Before" / "After"
  • Mac vs iPhone extension sets — desktop Safari toolbar layouts differ; caption lines written for phone captures may need rephrasing for Mac frames

Apple Connect field limits (extension listing text)

Safari extension product pages use the same core listing field caps as other App Store apps on the zh-Hans row. CJK characters count toward the same limits as Latin letters — plan shorter Chinese phrasing than English drafts.

  • App name (title) — up to ~30 characters; should signal extension function, not only the companion app brand
  • Subtitle — up to ~30 characters; one fact the title does not repeat — what Safari users get after enabling
  • Keywords — up to ~100 characters; extension-specific search terms separate from companion app keywords
  • Description — long listing body explaining enable steps, Safari Settings path, and sync with the companion app
  • Promotional text — up to 170 characters; updatable without a new binary when you ship extension feature updates
  • Screenshot overlay captions — per-frame text on toolbar, popup, and permission-flow captures

Safari Web Extensions require users to enable the extension in Safari Settings after install — strong zh-Hans description copy should mention that flow in plain language without sounding like a support ticket.
