Files and Folders-specific listing vocabulary — what translates differently

Folder-access marketing on App Store pages uses vocabulary general disk-access or file-manager guides rarely cover. zh-Hans copy should reflect how Chinese App Store readers evaluate Files and Folders permission claims:

China storefront copy often uses 文件与文件夹 for general Files and Folders positioning aligned with Settings → Privacy & Security → Files and Folders, 文件与文件夹权限 when the hero frame shows the permission rationale or access scope, 文稿 for Documents folder grants, 桌面 for Desktop folder grants, and 下载项 for Downloads folder grants. AppLocale picks commerce-idiomatic phrasing per frame — not 完全磁盘访问 on scoped folder screenshots, not 隐私偏好策略控制 on consumer grant panels, and not 文件 Browse sidebar chrome on TCC permission walkthroughs.

Files and Folders vs Full Disk Access

Consumer Files and Folders (文件与文件夹) lets end users toggle per-app access to specific folders like Documents, Desktop, and Downloads in System Settings after consent. Full Disk Access (完全磁盘访问) lets apps read protected paths across the file system beyond normal sandbox limits — Mail, Messages, system logs, and other TCC-protected areas. English shares "file access" — Chinese storefront copy must not conflate scoped 文件与文件夹 folder grants with broad 完全磁盘访问 FDA marketing. Full Disk Access frames belong on the Full Disk Access listing guide when FDA leads — not mixed into per-folder Files and Folders captions unless each frame is labeled honestly.

Files and Folders vs PPPC

Consumer Files and Folders (文件与文件夹) lets end users toggle per-app folder grants in System Settings after consent. PPPC (隐私偏好策略控制) lets IT admins deploy PrivacyPreferencesPolicyControl payloads that pre-grant or deny Files and Folders for named apps on enrolled Macs. PPPC frames and files-and-folders-mdm grant intents belong on the PPPC listing guide when MDM TCC grants lead — not mixed into consumer folder grant captions unless each frame is labeled honestly.

Files and Folders vs Files app Browse hub

TCC Files and Folders permission (文件与文件夹) governs whether apps may access user folders after grants in System Settings. The Files app (文件) is Apple's file manager with Browse sidebar locations — Recents, Shared, On My iPhone, Tags, Connect to Server. A System Settings folder toggle is not a Files → Browse sidebar screenshot. Files app frames belong on the Files app listing guide when the Browse hub leads.
