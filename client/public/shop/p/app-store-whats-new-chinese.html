What's New vs promotional text vs description

App Store Connect treats three copy slots differently on the zh-Hans localization row:

  • What's New — version-specific release notes submitted with each build. Returning users read this first after an update. Empty or English-only notes on a zh-Hans page signal neglect.
  • Promotional text — up to 170 characters above the description; can often be updated without a new binary (verify in Connect). Use for timely news: a feature launch, a holiday theme, a bug fix users asked for.
  • Description — evergreen product copy. What's New and promotional text are not places to repeat your full feature list or stuff search keywords.

This page covers update notes and promotional text only — not title, subtitle, or keyword field work. For those fields, see our Simplified Chinese keywords guide or China storefront listing guide.

Common mistakes on zh-Hans update notes

  • Shipping English release notes while the rest of the listing is Simplified Chinese
  • Pasting Google Translate output with formal false cognates (“专业级”, “强大”) that read as template copy
  • Repeating the subtitle or first paragraph of the description in What's New every version
  • Stuffing search keywords into release notes — Apple indexes description and keywords, not What's New for Search
  • Listing internal bug-fix ticket numbers or developer jargon Chinese users do not recognize
  • Leaving promotional text empty while competitors use the slot for seasonal offers

Better zh-Hans update notes reduce confusion after an update — they do not replace in-app UI localization or Apple review decisions.

What good zh-Hans What's New looks like

Lead with what changed for the user, not how you built it. One or two short paragraphs — bullet lists are fine when each item names a visible outcome:

  • Name the feature in plain Chinese: “新增桌面小组件” not “优化用户体验”
  • Call out breaking changes or migration steps if existing users need to act
  • Match tone to your description — casual productivity app vs professional tool
  • Keep promotional text to one or two crisp clauses: what launched, who benefits, any time limit

zh-Hans and en-US update notes can differ idiomatically when the news is the same — avoid mirroring comma-heavy brochure lines from your English page.
