What good zh-Hans tvOS listing copy looks like

Apple TV product page copy should name what the buyer experiences in a living-room context — not a copy-paste of iPhone slogans:

  • Name and subtitle — when platform-specific fields are set, use concise Chinese that matches how Apple TV users search; avoid English codenames unless trademark requires them
  • Promotional text — one timely hook (launch, season, feature) within the 170-character cap; updatable without a new binary when you maintain a tvOS-specific promo line
  • 16:9 screenshot captions — one outcome per widescreen frame: playback quality, multi-user sign-in, game controller support, or catalog browsing visible in that capture
  • App Preview metadata — preview title and description describe the lean-back workflow shown in the clip, not the iPhone trailer script
  • Remote-friendly phrasing — describe focus navigation and select actions instead of touch gestures when the screenshot shows TV UI chrome
  • Voice match — same 你/您 and punctuation habits as your zh-Hans description and iPhone gallery

zh-Hans widescreen captions can differ idiomatically from en-US lines when the on-screen feature is the same — avoid mirroring comma-heavy English brochure phrasing onto 16:9 living-room art.
