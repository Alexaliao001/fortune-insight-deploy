How a stale zh-Hans row drifts from your current listing

App Store Connect does not auto-sync zh-Hans when you edit en-US. Each localization row is independent. Over years of US-first shipping, these gaps accumulate:

  • Title and subtitle drift — en-US got a shorter brand name or new subtitle hook; zh-Hans still uses the old translation of a retired tagline
  • Description describes v1 — long Chinese body copy still lists workflows, integrations, or pricing models you removed
  • Keywords frozen — the 100-character zh-Hans keyword block still targets search terms from an old category positioning
  • Promotional text empty or ancient — the 170-character slot still mentions a 2021 launch or sits blank while competitors update seasonally
  • Screenshot gallery lag — en-US screenshots were refreshed for a dark-mode redesign; zh-Hans gallery still shows light-mode UI from three years ago
  • What's New neglect — every build submission copies English release notes; returning Chinese users see a bilingual-trust break on every update

Buyers on the China storefront may still find your app — but the product page reads abandoned. That is different from an empty row (English fallback) and different from a single-field What's New gap. It is a full-row refresh problem.

Audit checklist before you rewrite

Compare side by side: your live en-US App Store page, your live China storefront page, and the app build currently in production. Note every mismatch:

  1. Name (~30 characters) — Does the Chinese title still match how users know the app after your last rebrand?
  2. Subtitle (~30 characters) — Does it state the current primary outcome, not a feature you deprecated?
  3. Keywords (~100 characters) — Do terms still reflect how China Search users look for this category today?
  4. Description — Does the long body mention only features that exist in the current binary?
  5. Promotional text (170 characters) — Is there timely news, or a line from an old campaign?
  6. Screenshots and caption lines — Does gallery art match current UI? Do overlay lines describe on-screen elements accurately?
  7. What's New — Scroll your last five versions in Connect; if every zh-Hans note is English or copy-pasted from 2022, flag it for rewrite

If Review recently flagged metadata accuracy or localization quality, map their note to this checklist before resubmitting — see App Store rejection for incomplete zh-Hans localization.
