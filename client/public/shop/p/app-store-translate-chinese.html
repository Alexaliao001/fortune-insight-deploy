Translation-specific listing vocabulary — what translates differently

Translation listings use vocabulary general utility guides rarely cover. zh-Hans copy should reflect how Chinese App Store readers evaluate 翻译 claims — not a literal paste of US marketing:

On-device translation vs cloud translation

US pages say "On-device translation" or "Works offline." China storefront copy often uses 设备端翻译, 离线翻译, or 本地翻译 — depending on whether you mean Apple's on-device models, your own bundled models, or network-required API calls. AppLocale aligns phrasing with your actual offline scope, not inventing 离线 when your gallery shows a loading spinner for cloud API.

Live translation vs document translation

实时翻译 and 即时翻译 signal conversation or live-preview UX. 文档翻译 or 全文翻译 signal batch or file workflows. Mixing them on one subtitle when your app only does one mode confuses China buyers at install.

Subtitle and keyword packing

The 30-character subtitle and 100-character keyword field need translation search terms Chinese buyers type — see Simplified Chinese keywords & subtitle for field mechanics. Terms like 翻译, 实时翻译, and 文本翻译 each signal different intent from generic productivity keywords.

Screenshot captions on translation frames

Gallery frames that show bilingual panels, language pickers, or live translation previews need one-line zh-Hans captions — "一键翻译任意文本" or "支持多语种实时互译" not "Translate text" burned into the product page story.

Common mistakes on translation-themed zh-Hans listings

  • Assuming translation integration localizes automatically — on-device or API translation shipped in the binary; zh-Hans row never added or left blank
  • Only translating the description — subtitle, keywords, and translation screenshot caption lines still English
  • Conflating translation with Live Text OCR — listing says 复制照片文字 when the app translates typed text, not extracts text from images
  • Conflating translation with VoiceOver or Dictation — speech input for accessibility is not the same as live bilingual translation marketing
  • English "Translate" on zh-Hans screenshots — Connect caption fields are Chinese but burned-in overlay labels on PNG exports are still Latin
  • Overclaiming Apple Translate — marketing implies native Apple Translate integration when your app uses a custom engine or third-party API
  • What's New still English after translation launch — see What's New in Simplified Chinese when new language pairs or offline mode shipped in a recent version
